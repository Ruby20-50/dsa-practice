## CamelCase

**Problem:** Given S, determine the number of words in S.
[HackerRank link](https://www.hackerrank.com/challenges/camelcase/problem)

**Approach:** Iterate the string once, increment a counter each time an uppercase is found, starting the count at 1.
**Difficulty:** easy

**Complexity:**
- Time: O(n)
- Space: O(1)

**Languages:** Java, Python
