## Staircase
**Problem:** Given an integer `n`, print a staircase of height and width `n`, using `#` and spaces. Last line has no leading spaces.
[HackerRank link](https://www.hackerrank.com/challenges/staircase/problem?isFullScreen=true)

**Approach:** For each row `i` (1 to n), print `(n-i)` spaces then `i` hashes.

**Difficulty:** Easy

**Complexity:**
- Time: O(n²)
- Space: O(1)

**Languages:** Java, Python
